## Задачи после первого занятия

### 1. Сформировать команды (3-4 человека)

**Что сделать:**
- Объединиться в команды по 3-4 человека
- Если есть "сироты" (студенты без команды) — сообщить преподавателю
- Преподаватель поможет распределить студентов по командам

**Критерий успеха:**
- [ ] Все студенты распределены по командам
- [ ] Каждая команда состоит из 3-4 человек

---

### 2. Набросать 3 идеи бизнес-приложения

**Что сделать:**
Каждая команда предлагает 3 идеи бизнес-приложения на FastAPI.

**Формат для каждой идеи:**

```markdown
## Идея 1: [Название]

**Описание:** Краткое описание (1-2 предложения).

**Основная сущность:** Что будем CRUDить (например, "задачи", "заявки", "бронирования").

**Целевая аудитория:** Кто будет использовать (например, "студенты кампуса", "сотрудники офиса").

**Примеры эндпоинтов:**
- `POST /tasks` — создать задачу
- `GET /tasks` — получить список задач
- `PUT /tasks/{id}` — обновить задачу
- `DELETE /tasks/{id}` — удалить задачу

**Сложность:** [Низкая / Средняя / Высокая]
```

**Примеры тем (для вдохновения):**
- Система учета заявок для кампуса
- API для бронирования переговорных комнат
- Бэкенд для трекинга задач (аналог Trello)
- Система управления курсами (LMS)
- API для сервиса доставки еды
- Система управления библиотекой
- API для фитнес-трекера
- Система управления мероприятиями

**Критерий успеха:**
- [ ] Предложено 3 идеи
- [ ] Каждая идея содержит описание, сущность, аудиторию, примеры эндпоинтов
- [ ] Идеи реалистичны (можно реализовать за семестр)
